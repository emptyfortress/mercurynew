# Main goal

Текущая задача - разработка сервиса Workflow (бизнес-процессов).

## Current work

Мы пытаемся представить, как может выглядеть страница Процессов

Она должна содержать

- шаблоны процессов
- запущенные процессы

## Main components for the task

- стартовые компоненты:
  - src/views/Process.vue

создай этот компонент

## Business logic

- Страница должна показывать как шаблоны, так и запущенные процессы.
- это предполагается единой точкой входа в процессы
- Поскольку шаблонов могут быть десятки-сотни, а процессов - тысячи обычный список не удобен
- Люди будут искать либо по названию шаблона (может быть по категории), либо по свойствам процесса (активные, ошибки, приостановленные, заершенные, автор и тп.)

## Idea

- Использовать treemap диаграмму из apexcharts для данной страницы.
- зоны на диаграмме разбиты по типам процессов (шаблоны и running processes), а также по названию шаблонов (категории?), и по свойствам процесса
- навигация происходит по клику на зону на диаграмму - мы "проваливаемся" в этот тип или шаблон
- после 2-3 шагов навигации по диаграмме показываем обычный список процессов или шаблонов
- необходимо предусмотреть возврат "наверх" на предыдущий вид - может быть что-то вроде breadcrumbs?
- предусмотреть и простой поиск-фильтр
