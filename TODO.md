# Main goal

Текущая задача - создание новой страницы Нумераторы

## Current work

Создаем страницу и постепенно наполняем ее функционалом.

## Main components for the task

- компонент:
  - создай папку внутри src/components и складывай туда компоненты нумератора

## Навигация

- Пользователь попадает в нумератор со страницы /dvmain
- На ней уже есть плашка «Нумераторы». Нужно её раздизаблить и настроить пути.
- Титул страницы должен содержать "Нумераторы".
- Бредкрамс тоже должен содержать слово «нумераторы».

## Layout

Используем стандартную схему страницы, как в конструкторе шаблонов (src/components/process/ProcessConstructorContent.vue):

- слева список правил (нумераторов) с кнопкой + для создания нового
- справа (через сплиттер) сам конструктор
- есть кнопка, чтобы прятать-показывать список нумераторов
