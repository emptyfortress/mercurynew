## Main functions

- Каждый вид и тип документа имеет список доступных операций и список переходов между состояниями.
- Когда мы открыли конструктор мы уже работаем с каким-то видом документа
  Операции:
- Нужна возможность добавить операции к выбранному состоянию из списка
- Нужна возможность удалить операцию из списка
- Нужна возможность создать новую операцию, добавить ее в общий список и к выбранному состоянию

  Переходы:

- при выборе узла в диаграмме в табе Переходы мы видим все переходы для данного узла (состояния)
- Нужна возможность добавить переход к текущему состоянию (выбранному узлу в диаграмме) из списка
- Нужна возможность удалить переход из списка
- Нужна возможность создать новый переход, добавить ее в общий список и к выбранному состоянию
- Переход - это связь между состояниями (edge on diagramm), которая переводит документ из одного состояния в другое
- При создании перехода необходимо выбрать целевое состояние, куда перейдет текущее состояние
- В списке переходов для каждого состояния может быть один дефолтный переход
- Дефолтный переход выделяется жирным шрифтом и чекбоксом в списке переходов

## Requirements

- В начальном состоянии список операций пуст. Выводится соответствующее сообщение и кнопка Добавить операцию
- Добавление операций производится из модального окна
- В модальном окне показываем список всех ДОСТУПНЫХ операций для данного вида
- Можно выбрать только одну или несколько операций
- Можно отфильтровать операции по имени
- Можно добавить новую операцию в список доступных и сразу выбрать ее для текущего состояния
- Новая операция состоит из названия и опционального описания
- при добавлении новой операции нужно предусмотреть локализацию названия и описания
- желательно избежать наложения двух модальных окон друг на друга.
- используй подходы, которые уже опробованы в табе Операции
