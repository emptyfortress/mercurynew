# Main goal

Текущая задача - добавляем поиск в центр настроек

## Current work

Нужно добавить функцию поиска по всему центру настроек. После проверки будет приниматься решение об реализации.

## Main components for the task

- стартовый компонент:
  - src/App.vue
	- src/components/decision/Databases.vue 

## Task

- Нужно добавить на топ-бар поле ввода для поиска с иконкой лупы
- по клику в поле ввода открывать модальное окно для поиска (как в Raycast)
- в модальном окне опять показываем поле ввода
- ниже - история поисков
- при начале ввода история заменяется на совпадения в настройках
- можно клавиатурой перейти на список совпадений и выбрать нужное

## Restrictions

- реализовывать сам поиск не нужно
- при открытии окна поиска показать фиктивную историю
- предположим, что юзер будет вводить термины:
	- роли, роль
	- разметки
	- мониторинг
	- колонки

Для этих случаев показываем результаты поиска из наших конструкторов (список приведен на стр Databases.vue)
По клику на один из результатов отправляем юзера туда.
