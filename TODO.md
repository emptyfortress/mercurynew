# Main goal

Мы разрабатываем страницу конструктора состояний для процессов и документов.
Конструктор должен уметь:

- создавать-удалять-редактировать состояния в визуальном редакторе VueFlow
- настраивать связи между состояниями

- настраивать свойства связей

## Business logic

- Каждый вид документа имеет 3 сущности: список состояний, список операций, список переходов
- Состояния - это узлы на диаграмме VueFlow (nodes)
- Переходы - это связи между узлами (edges)
- Операции - это просто список всех возможных операций для данного вида документа
  - У каждого состояния есть разрешенные для него операции из общего списка
  - Каждый переход должен быть привязан к конкретной разрешенной операции

- В начальном состоянии на диаграмме 3 дефолтных узла соединенных переходами

## Right panel (properties) behaviour

### Nothing selected

- пока в диаграмме ничего не выбрано - правая панель содержит 3 таба: Состояния, Операции, Переходы
- В каждом табе общий список соответствующих сущностей с кнопкой + для добавления

### Selection

- при выборе узла в диаграмме в правой панели отображаются его свойства, а именно:
  - Поле Название (+ локализации)
  - чекбокс Исходное состояние
  - QTabs c двумя табами: Операции, Переходы
    Операции: - В табе Операции показываем имеющуюся таблицу операций - над таблицей есть фильтр в виде QChips: Разрешенные, Все - фильтр показывает либо все операции, либо только разрешенные для данного состояния
    Переходы: - В табе Переходы показываем таблицу имеющихся связей - Колонки таблицы: связываемые узлы, привязанная операция - над таблицей есть фильтр в виде QChips: Исходящие, Входящие, Все

- при выборе связи в диаграмме в правой панели отображаются ее свойства, а именно:
  - привязанная оперция
  - исходное и конечное состояния
